# Modül 6: Endüstriyel Protokoller ve Test

Bataryanın araç veya enerji depolama sistemi (ESS) ile haberleşmesi ve tüm sistemin doğrulanması bu modülün konusudur.

## 📚 Teorik Konular

1.  **Haberleşme Protokolleri:**
    *   **CAN-Bus (Controller Area Network):** Otomotiv standardı.
    *   **CAN-FD:** Daha yüksek veri hızı.
    *   **J1939:** Ağır vasıta standartları.
2.  **Test Metodolojileri:**
    *   **SIL (Software-in-the-Loop):** Kodun simülasyon ortamında testi.
    *   **HIL (Hardware-in-the-Loop):** Gerçek BMS donanımının simüle edilmiş pil paketine bağlanması.
3.  **DBC Dosyaları:** CAN mesajlarının tanımlanması ve işlenmesi.

## 🛠 Kullanılan Araçlar
- Vector CANoe / CANalyzer
- PCAN-View
- dSPACE / Speedgoat (HIL Sistemleri)
